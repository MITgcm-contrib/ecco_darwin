# Kerguelen Plateau ~1 km regional ECCO-Darwin configuration

A ~1 km, 90-level regional ocean/biogeochemistry configuration over the
Kerguelen Plateau, downscaled from ECCO-Darwin LLC270 v05 (v5r1) with the
`regions/downscaling` toolkit.

| | |
|---|---|
| Grid | 1170 x 1008 x 90, lat/lon, uniform spacing |
| Extent | 62.000 – 78.007 E, 54.000 – 44.996 S |
| Resolution | 0.0136811 lon x 0.0089330 lat (~0.99 x ~0.99 km) |
| Vertical | 90 levels, 1 m at the surface |
| Period | 2020-01-01 to 2023-01-01 (3 years) |
| Timestep | 90 s (1,052,160 steps) |
| Decomposition | sNx=39 sNy=42, nPx=30 nPy=24 = 720 MPI ranks |
| Parent | ECCO-Darwin LLC270 v05 (v5r1), 31-tracer Darwin |
| Open boundaries | all four (N/S/E/W), hourly, prescribed from the parent |
| Atmospheric forcing | ERA5 |

## What is **not** here

The repository holds text configuration only. Everything the model actually
reads as data is generated by the downscaling pipeline and is far too large to
version:

| artifact | approx. size | produced by |
|---|---|---|
| `kerguelen_ncgrid.nc` | ~7 GB | STEP1 |
| `kerguelen_bathymetry.bin` | ~5 MB | STEP1 |
| parent `diagnostics_vec` extraction | ~60 GB | STEP2 |
| OBCS boundary files (164) | ~100 GB | STEP3 |
| initial-condition pickups (78) | ~50 GB | STEP3 |

`PIPELINE.md` documents how each is regenerated.

## Two things that will silently misconfigure a rebuild

Both are ordering rules, and neither produces an error if you get them wrong.

1. **`genmake2 -mo` order is `code_darwin` then `code`.** Both directories
   contain `OBCS_OPTIONS.h` and `DIAGNOSTICS_SIZE.h`, and genmake2 takes the
   first match. `code_darwin/OBCS_OPTIONS.h` is therefore the file that
   governs — including `ALLOW_OBCS_SPONGE`, which is `#define`d there.
   (`code/OBCS_OPTIONS.h` carries an inert `#undef` of the same macro; it is
   overridden and has no effect on the build.)

2. **Copy `input/` first, then `input_darwin/`.** The latter overwrites
   `data.diagnostics`, `data.obcs` and `data.pkg`. Reversed, you get a
   physics-only run that starts and integrates normally.
