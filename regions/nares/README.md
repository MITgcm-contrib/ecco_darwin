# Nares Strait 1 km regional ECCO-Darwin configuration

A 1 km, 90-level regional ocean, sea-ice and biogeochemistry configuration of
Nares Strait (Lincoln Sea to the North Water), downscaled from ECCO-Darwin
LLC270 v05 (V5r1) with the `regions/downscaling` toolkit. Target: the Nares
ice arches, their formation and collapse, and their effect on the ecosystem.

**STATUS (2026-11-16): DRAFT. The physics is not frozen.** A stop rule allows
at most two more full 2015 runs. Run 1 of 2 (`run_arch_D10`, ice-ocean drag on
the top-10-m current) is running. Every value marked "DRAFT" below can still
change. See `OPEN_QUESTIONS.md`.

## What is **not** here

The repository holds text configuration only. Everything the model reads as
data is generated by the pipeline and is too large to version:

## Four things that will silently misconfigure a rebuild

0. **The model tree is public darwin3 at tag `darwin_ckpt69k` PLUS `pkg/iceplume`.**
   Copy `v05/pkg/iceplume/` into `darwin3/pkg/` before genmake2. `code/`
   carries two `pkg/seaice` overrides (`SEAICE.h`, `seaice_init_fixed.F`)
   that backport `SEAICE_SWFrac` from darwin3 master, which `seaice_growth.F`
   needs. See `readme_pleiades.txt` section 1.

1. **`genmake2 -mo` order is `code_darwin` then `code`.** The first match wins.
   `code/` is the collapsed physics build (`build_drag10`). `code_darwin/`
   holds only the 18 Darwin files that differ from `code/`. A build with
   `code/` alone reproduces the physics binary. See `PROVENANCE.md`.

2. **Copy `input/` first, then `input_darwin/`.** The latter overwrites
   `data.pkg` (BGC packages on) and `data.diagnostics` (BGC streams added).
   Reversed, you get a physics-only run that starts normally.

3. **The run directory needs `tile001.mitgrid` AND `Nares_grid18.face001.bin`.**
   exch2 reads the facet geometry from `tile001.mitgrid` (= `Nares.mitgrid`).
   `data` sets `horizGridFile = 'Nares_grid18'`, so the model also reads the
   18-field file with AngleCS/AngleSN. Without it the model computes the grid
   angles itself and gets the east and north edge rows wrong by up to 167
   degrees (wind rotation). `Nares_bathymetry.bin` in the run directory must be
   a link to `Nares_bathymetry_walled.bin`.

## Provenance

`v05/pkg/iceplume/` is Mike Wood's package, [https://github.com/mhwood/iceplume](https://github.com/mhwood/iceplume) (commit
[e4d4ac9](https://github.com/mhwood/iceplume/commit/e4d4ac9)), with 13 local fixes; its `README.md` and `LICENSE` are inside.
Downscaled with `ecco_darwin/regions/downscaling` plus Nares-specific scripts
(`scripts/pipeline/`). The decision log (`DECISIONS.md`, about 1400 dated
bullets) and the BGC plan (`BGC_PLAN.md`) are working documents and are not
part of this repository.
