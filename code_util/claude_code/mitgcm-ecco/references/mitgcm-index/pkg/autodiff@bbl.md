## README
```
c
c
c   =========================================
c   Adjoint support Package for the MITgcmUV
c   =========================================
c
c   Current Version: 0.1.0 (20-Jun-2000)
c
c
c   General Outline:
c   ----------------
c
c      The directory autodiff only contains pieces
c      of code that are of general use in getting
c      the adjoint or the tangent linear model of
c      a some MITgcmUV setup.
c
c      Such pieces are hand-coded adjoint routines,
c      initialization and finalization of a future
c      autodiff package, flow directives for TAF
c      and header files necessary to include for
c      doing automatic differentiation.
c
c   ========
c   HISTORY:
c   ========
c
c
c   started: Christian Eckert eckert@mit.edu  1999
c
```

## CPP options (defaults as shipped)
- `ALLOW_AUTODIFF_TAMC` (define, AUTODIFF_OPTIONS.h) — o Include/exclude code in order to automatically differentiate MITgcm code using TAF (Transformation of Algorithms in Fortran, http://www.FastOpt.de) or using TAMC (Tangent Linear & Adjoint Model Compiler, needs both def
- `AUTODIFF_TAMC_COMPATIBILITY` (undef, AUTODIFF_OPTIONS.h)
- `ALLOW_TAMC_CHECKPOINTING` (define, AUTODIFF_OPTIONS.h) — >>> Checkpointing as handled by TAMC
- `ALLOW_AUTODIFF_MONITOR` (define, AUTODIFF_OPTIONS.h) — >>> Extract adjoint state
- `ALLOW_AUTODIFF_MONITOR_DIAG` (define, AUTODIFF_OPTIONS.h) — >>> and DYNVARS_DIAG adjoint state
- `AUTODIFF_2_LEVEL_CHECKPOINT` (undef, AUTODIFF_OPTIONS.h) — >>> DO 2-level checkpointing instead of 3-level
- `AUTODIFF_4_LEVEL_CHECKPOINT` (undef, AUTODIFF_OPTIONS.h) — extend to 4-level checkpointing
- `ALLOW_DIVIDED_ADJOINT` (undef, AUTODIFF_OPTIONS.h) — o use divided adjoint to split adjoint computations
- `ALLOW_AUTODIFF_WHTAPEIO` (define, AUTODIFF_OPTIONS.h) — o This flag is incredibly useful as it reduces the number of tape-files on the disc. Maybe it should even be the default.
- `ALLOW_INIT_WHTAPEIO` (undef, AUTODIFF_OPTIONS.h) — and related to above:
- `AUTODIFF_USE_STORE_RESTORE` (undef, AUTODIFF_OPTIONS.h) — are collected in a single buffer field array before storing to tape. This functionality has been replaced by WHTAPEIO method (see above). Might still be used for OBCS since WHTAPEIO does not support OBCS fields.
- `AUTODIFF_USE_STORE_RESTORE_OBCS` (undef, AUTODIFF_OPTIONS.h)
- `AUTODIFF_ALLOW_VISCFACADJ` (define, AUTODIFF_OPTIONS.h) — o allow using viscFacInAd to recompute viscosities in AD
- `AUTODIFF_DISABLE_LEITH` (undef, AUTODIFF_OPTIONS.h) — o To remove part of MOM_CALC_VISC (better name would be: MOM_DISABLE_*)
- `AUTODIFF_DISABLE_REYNOLDS_SCALE` (undef, AUTODIFF_OPTIONS.h)
- `AUTODIFF_EXCLUDE_ADEXCH_RS` (undef, AUTODIFF_OPTIONS.h) — which might not always be generated by TAF (e.g., when controls do not include any 2D forcing field). In those cases, defining this cpp-option allows to circumvent this missing code issue.
