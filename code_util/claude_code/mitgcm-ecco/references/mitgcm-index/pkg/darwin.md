# pkg/darwin  (darwin3: ~/Documents/GitHub/darwin3)

darwin3 Darwin ecosystem model: many plankton types/groups (allometric or random traits), nutrients, carbon chemistry, iron, radtrans light; called via gchem.

**runtime switch:** `useDARWIN`-style flag in `data.pkg` (check exact name in packages_boot.F)
**reads:** `data.darwin`, `data.traits`
