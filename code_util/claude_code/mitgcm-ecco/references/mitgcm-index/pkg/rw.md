# pkg/rw

Read/write utilities on top of mdsio (READ_FLD_XY_RL etc.); always compiled.

**in groups:** gfd
**always-on utility package** (no data.pkg switch)
**manual:** `doc/getting_started/getting_started.rst`, `doc/outp_pkgs/outp_pkgs.rst`
**adjoint support files:** rw_ad_diff.list

## CPP options (defaults as shipped)
- `RW_SAFE_MFLDS` (define, RW_OPTIONS.h) — use READ_MFLDS S/R in "safe" mode (set/check/unset for each file to read) involves more thread synchronization (could slow down multi-threaded run)
- `RW_DISABLE_SMALL_OVERLAP` (undef, RW_OPTIONS.h) — disable writing of small-overlap size array (to reduce memory size since those S/R do a local copy to 3-D full-size overlap array)

## Headers
- `RW_MFLDS.h` — \bv Variables used for reading Multi-Fields files (+ meta-file) This block allows to shared information across threads and between READ_MFLDS subrouti
- `RW_OPTIONS.h` — CPP options file for Read-Write (RW) package Use this file for selecting options within the RW package
